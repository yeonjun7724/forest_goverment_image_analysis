# 🌲🛰️ 산림행정 실무를 위한 위성영상 활용 및 변화탐지 실습

2026년 제2기 산림공간정보시스템과정(산림교육원) 강의 교재와 QGIS 실습 패키지입니다.
Sentinel-2 위성영상과 공식 공간정보를 QGIS로 다루어 **산림 변화지역과 국유림 무단점유 의심지역을 찾고, 현장조사 후보지를 지도와 표로 정리**하는 과정을 다룹니다. 모든 실습은 프로그래밍 없이 QGIS 메뉴·대화상자 조작만으로 진행합니다.

> ⚠️ 실습의 국유림 경계(`교육용_가상국유림`)는 **교육용 가상 경계**입니다. 실습 결과는 실제 무단점유·위법 여부와 무관하며, 현장조사 후보지 선정 연습용 자료입니다.

## 🧪 실습 흐름

1. **실습 1 – 국유림 무단점유 의심지역 탐색**: T1·T2 트루컬러 영상을 비교해 의심 지점을 판독
2. **실습 2 – 다중시기 변화탐지**: NDVI 계산(BOA 오프셋 보정) → dNDVI → SCL 유효화소 마스크 → 변화등급 → Sieve → 8방향 폴리곤화
3. **실습 3 – 현장조사 우선순위와 결과지도**: 관리 경계 교차 → 면적 계산 → 0.1ha 미만 자투리 정리 → 원인 판독 결합 → 우선순위 점수 → CSV/XLSX/GPX·결과지도

## 🗺️ 자료 개요

- **사례지**: 경상북도 안동시 일직면·남후면 일대, 약 5km × 5km (중심 128.6559°E, 36.48933°N)
- **영상**: Sentinel-2 L2A, 타일 T52SDF — T1 2024-05-31, T2 2025-06-05, T0 2024-11-07(계절 비교 심화)
- **좌표계**: 영상 EPSG:32652(UTM 52N, 10m), 벡터·면적 EPSG:5186, GPX만 EPSG:4326
- **NDVI**: `(B08 - B04) / (B08 + B04 - 2000)` (BOA_ADD_OFFSET = -1000 반영)
- **환경**: QGIS 3.44 기준

## 📜 자료 출처 및 이용조건

- Contains modified Copernicus Sentinel data (2024, 2025), Copernicus Data Space Ecosystem
- 연속지적도: 국토교통부 브이월드 2D 데이터 API (LP_PA_CBND_BUBUN), 2026-10-15 조회
- 임상도(1:25,000, 제5차): 산림청 산림공간정보서비스 — 비영리 공공사업·학술연구 목적

연속지적도·임상도의 재배포 조건이 확인될 때까지 이 저장소는 비공개로 유지합니다.
