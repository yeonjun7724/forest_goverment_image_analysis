산림 변화탐지 실습 패키지 (교육용)
=====================================
과정: 2026년 제2기 산림공간정보시스템과정 / 산림행정 실무를 위한 위성영상 활용 및 변화탐지 실습

[중요 안내]
- 교육용_가상국유림은 실제 국유림 경계가 아니며, 실습 결과는 실제 무단점유 여부와 무관합니다.
- 결과물은 현장조사 후보지 선정용 교육 자료이며, 위법 여부를 판단한 자료가 아닙니다. 외부에 공유하지 마십시오.

[자료 출처]
- Contains modified Copernicus Sentinel data (2024, 2025). Sentinel-2 L2A, 타일 T52SDF, Copernicus Data Space Ecosystem.
    T1 S2B_MSIL2A_20240531T021529_N0510_R003_T52SDF_20240531T042042 (처리 기준판 05.10)
    T2 S2B_MSIL2A_20250605T021529_N0511_R003_T52SDF_20250605T041606 (처리 기준판 05.11)
  화소값(DN)은 BOA_ADD_OFFSET = -1000, QUANTIFICATION_VALUE = 10000 (제품 메타데이터에서 확인).
  NDVI = (B08 - B04) / (B08 + B04 - 2000)
- 연속지적도: 국토교통부 브이월드 2D 데이터 API(LP_PA_CBND_BUBUN), 2026-10-15 조회. 필지 속성의 고시연월은 필지별로 상이(2011~2025년). 
  지목은 지번(jibun) 문자열의 마지막 글자(전·답·임 등)이며, 이 패키지에서 jimok 필드로 분리했습니다. 이용조건은 강사 확인 필요.
- 임상도(1:25,000): 산림청 임상도(제5차, 경상북도 47), 산림공간정보서비스 다운로드 신청으로 확보. 원본 좌표계 EPSG:5179를 EPSG:5186으로 변환해 AOI로 절단.
  임상 필드: FIFTH_FRTP(임상코드; FRTP_NM은 코드 정의서 기준 임상명), DMCLS_CD(경급), AGCLS_CD(영급), DNST_CD(밀도). 자료 파일에는 기준일 정보가 없어 기준일은 미확인입니다.
  이용범위: 산림청 안내 기준 비영리 공공사업·학술연구 목적. 교육 배포 가능 여부는 강사 확인 필요.

[좌표계]
- 영상(01_image): EPSG:32652 (WGS84 / UTM 52N), 10m 격자. 재투영하지 않고 계산합니다.
- 벡터(02_vector)와 면적 계산: EPSG:5186 (Korea 2000 / Central Belt 2010).
- 위경도(EPSG:4326)에서는 면적을 계산하지 않습니다. GPX만 4326입니다.
